REKAPYUK LOKAL
==============
Isi folder ini harus diunggah SEMUA ke satu tempat hosting statis gratis
(misalnya Netlify, Cloudflare Pages, atau GitHub Pages):
  index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png

Setelah online:
1. Buka alamatnya di Chrome HP, tunggu sampai halaman muncul (butuh internet).
2. Menu titik tiga > "Instal aplikasi" atau "Tambahkan ke layar utama".
3. Pertama kali baca screenshot, aplikasi mengunduh pembaca teks (OCR) sekali saja.
4. Data tersimpan di HP (di dalam browser). Pakai Setup > Backup data secara rutin.

Yang disimpan di hosting hanya kode aplikasi. Data keuanganmu tidak dikirim ke mana pun.
